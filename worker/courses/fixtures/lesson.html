First steps

A duck reads a query before it runs it. This lesson shows the first query, the setup, and the list of the steps that every duck follows on its first day. Read each step and run the example on your own machine.

Setup

Install the tool, then start the server. The server listens on the default port of the tool.

  • Install the tool
  • Start the server

The first query

Run this query to count the ducks in the pond. The answer is a single number.

SELECT count()
FROM ducks;
