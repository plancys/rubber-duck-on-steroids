Notes of the worker:

- A live query with consent fits OAuth 2.1 with PKCE, RFC 8707 and RFC 9728. MCP uses the same profile, so AI agents get the same path. Consent for each kind of data fits RAR. An agent that acts for the person fits Token Exchange.
- A signed claim that the person carries fits SD-JWT (an RFC) or VC Data Model 2.0 (a W3C Recommendation) as the format. OID4VCI 1.0 issues it, and OID4VP 1.0 shows only the claims that the person selects.
- Not verified: the date of general availability of the Supabase OAuth server, and its support for RAR and RFC 8707.

MCP servers:

- Honcho has an MCP server with 42 tools. It passes the key of the caller to the API (`honcho/mcp/src/config.ts:83-96`).
- Mem0 has no OpenMemory or MCP server code in `mem0/`, `server/` or `mem0-ts/`. Its plugins have one stdio tool, `search_memories`.
- The Memobase MCP server has three tools for one fixed user, and it listens on all addresses with no auth (`memobase/src/mcp/src/main.py:17,55,60-122,132`).
- Tutor MCP states `agent_delegation: false` in its discovery document (`tutor-mcp/auth/native.go:168-188`).
- knowledge-graph-mcp listens on all addresses with no auth and no owner column (`knowledge-graph-mcp/knowledge_graph_mcp/server.py:494-511`).
- Cognee has no MCP server in the clone.

Designs that the worker finds most useful (J):

1. One OAuth grant for each app, with read and write scopes and a stored consent. Add scopes for kinds of data (Tutor MCP).
2. Each app is its own principal with access lists for each dataset. The person sees all that the apps see (Cognee).
3. The token sets the part of the data that the model can read, and code limits the recall to that part (Honcho).

Traps (J):

1. The person is a field of the request, not a claim of the token (`mem0/server/main.py:411-453`, `memobase/src/server/api/api.py:135-274`).
2. Defaults that open everything: Memobase with no `ACCESS_TOKEN`, and Honcho with auth off (`honcho/src/security.py:328-329`).
3. No revocation for each app and no read audit: Honcho keys are stateless (`honcho/src/security.py:151-210`). Cognee keys are plain text by default (`cognee/modules/users/api_key/hash_api_key.py:4,35-39`).
