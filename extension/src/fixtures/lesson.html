Ducks in tables

A table keeps the ducks in rows. Each row holds one duck, and each column holds one fact about the duck. This lesson shows how to create the table and how to read it back.

Create the table

Run the statement below in the console. It creates a table with a name column and a weight column. The engine stores each column on its own, so a query that reads one column reads less data. 

CREATE TABLE ducks (name String, weight Float32)
ORDER BY name;

What you learn

  • How a table keeps rows
  • How a column store reads data

Read the duck docs for more facts. The next lesson adds data to the table and counts the ducks by weight.
